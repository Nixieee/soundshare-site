# Current SoundShare UI captures

Rendered October 1, 2026 from the production SwiftUI views in the SoundShare macOS project using ProductScreenshotTests. AirPods Pro and Sony headphones, battery values, and volumes are deterministic sample data. They are not hardware test results.

Source PNGs are 3× captures; WebP copies use quality 90. The menu-bar SVG is the app’s own template icon. The website supplies the surrounding desktop and clickable menu-bar presentation.

Each discovery, selection, listening, and volume capture now has matching light and dark variants. The shared ThemedProductImage component follows the root website theme via CSS, so saved themes and live switches use the correct native capture without waiting for hydration.
